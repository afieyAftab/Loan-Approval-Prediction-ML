# Loan-Approval-Prediction-ML

🏦 Loan Approval Prediction (Machine Learning)

 Project Overview
    This project is based on predicting whether a loan application will be approved or not using Machine Learning.
    It helps financial institutions make faster and data-driven decisions instead of manual evaluation.

 Objective
      Predict loan approval (Yes / No)
      Analyze applicant data
      Improve decision-making
      
 Dataset
     Includes features like:

    Gender, Education, Income
    Loan Amount, Credit History
    Property Area
    
Target:

    1 → Approved
    0 → Not Approved
    
 Technologies
    Python, Pandas, NumPy, Scikit-learn

 Methodology
    Data Preprocessing (missing values, encoding)
    Model Training (classification algorithms)
    Evaluation (accuracy, confusion matrix)
    
 Results
    Model predicts loan approval status
    Performance checked using accuracy
